Spesifikasi Teknis TV Display

Resolusi & Rasio

Optimized 16:9 landscape. Target: 1920×1080 Full HD. Responsive ke 1280×720 dan 3840×2160 (4K).

Real-time Engine

Phoenix LiveView via WebSocket. State changes push dari server — tidak ada polling, tidak ada refresh halaman.

Prayer Flow Timer

Server-side clock authority. T-5min → Pre-Adhan. T+0 → Adhan. T+iqamah → Prayer. T+15min → Default.

Auto Recovery

Reconnect otomatis jika internet putus. Cached prayer times tampil offline. Reconnect saat koneksi kembali.

Mosque Branding

Nama masjid, logo, theme selection, custom background. Dikonfigurasi admin dari dashboard.

Readability (5m+)

Font minimum 24px untuk info sekunder. Jadwal sholat 36-48px. Prayer mode 72-144px. Kontras putih/gelap 7:1+.
